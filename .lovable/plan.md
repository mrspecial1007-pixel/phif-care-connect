# صفحة الأصناف داخل مركز التقارير

## ما سيتم بناؤه
- إضافة بطاقة «الأصناف» إلى مركز التقارير وربطها بالمسار `/management/reports/items`.
- إنشاء صفحة أصناف Mobile-first وRTL ببحث محلي وبطاقات علمية compact تعرض المادة، التركيز، الشكل، عدد المستفيدين، ومصادر Actual وPHIF Supplier.
- إنشاء صفحة تفاصيل على `/management/reports/items/$itemId` بأقسام النظرة العامة، المستفيدين، PHIF Supplier، منتجات Actual، وحركة الصرف.
- إضافة واجهات مرئية لأزرار «إضافة صنف»، «تعديل تعريف الصنف»، و«تعديل السعر» دون حفظ أو ربط ببيانات فعلية.

## حدود التنفيذ
- بيانات عرض ثابتة داخل الواجهة فقط لتوضيح التصميم والتفاعل.
- لا تغييرات على قاعدة البيانات أو PHIF Bridge أو المزامنة أو الفواتير أو حسابات الأرباح.
- لا جداول عريضة ولا تمرير أفقي، مع Header واحد وبطاقات بمسافات 12–16px.

## التحقق
- فحص المسارين على عرض الهاتف والتأكد من عدم وجود تداخل أو تمرير أفقي.
- تشغيل اختبارات الواجهة الآمنة وفحص حالة المعاينة بعد التغييرات.
